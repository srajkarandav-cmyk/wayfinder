# Wayfinder: Hazard-Aware Pedestrian Navigation

Live demo: [Open Wayfinder] (https://srajkarandav-cmyk.github.io/wayfinder/)

Video demo:[Watch on Youtube] (https://youtu.be/Kn5LZ6h9aCo?)

A web app that compares a safe walking route and a direct route, and warns you when you approach a hazard. Built for the 2026 Congressional App Challenge.

## Features
- Safe route vs. direct route on an interactive map
- Walking simulation with hazard alerts and a safer-detour option
- Destination search
- Hazard reporting tab

## Built with
JavaScript, HTML, CSS, Tailwind CSS, Leaflet.js, OSRM routing API, GeoJSON, Photon geocoding, Esri map tiles

## Notes
- Hazard data in this version is demo data.
- I used Google Gemini to help write and debug the code. The idea, feature design, and testing are mine.
- Future ideas: 311 / public works data, nearby safe places, optional arrival-time sharing.
